## Original-asset brief: task completion ledger

**Planned, not performed.** Compare agents on a small fixed repository task set. Publish task definitions, version/price/date, permissions, prompts, run logs, failures, repeated-run counts and an artifact diff. Separate success from claims of success and manual rescue. Do not rank tools until those artifacts exist.
