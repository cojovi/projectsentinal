Use the [public correction and site-error form](https://github.com/cojovi/projectsentinal/issues/new) to report a factual or technical error. Include the article URL, the disputed passage, the proposed correction and supporting source links. The [owner website](https://cojovi.com) provides an additional public contact route.

**Do not send confidential tips or sensitive personal data in public issues.** This is not a secure tip service, and a response is not guaranteed. Read the [corrections policy and log](/corrections) for how changes are recorded.
