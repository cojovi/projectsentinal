Protocol Sentinel is served as a static site with client-side Aurora navigation. Hosting and network providers can process connection data such as IP addresses and request logs under their own practices. This page does not assert control over their retention.

The site includes Google Analytics with the existing measurement ID **G-4PBBYC5R3L**. Analytics requests may process browser, device, page and usage information and use browser storage under Google's configuration. You can block analytics requests with browser privacy controls; articles remain available without JavaScript.

Embedded or linked third-party resources may receive requests if loaded or followed. Comment providers are disabled. There is no newsletter intake on this site. Public GitHub issue reports are governed by GitHub's practices and are publicly visible; do not post private information. See [contact](/contact).

Third-party services apply their own privacy practices.
